# ilogia Arena

موقع ثابت (HTML/CSS/JS) جاهز لـ GitHub Pages.

1. ارفع محتوى المجلد إلى مستودع `mo-2012/arena---ilogia` (الفرع main).
2. Settings > Pages > Deploy from branch > main / root.
3. أضف سجل DNS من نوع CNAME للنطاق arena.ilogia-eg.com يشير إلى mo-2012.github.io (من لوحة النطاق، يدويًا).

التنقل بالـ hash (#/competitions) فلا يحتاج إعداد خوادم.
البيانات الحالية تجريبية ومحلية؛ الربط مع Supabase والتحقق من الدرجات من السيرفر لم يُنفّذ بعد.
